# 考试助手

按学习材料出题、记录对错与掌握度，并支持按学习历史或错题复盘练习、生成学习报告的 skill。

## 功能

- 根据你提供的文档、附件或粘贴内容出题，题型由材料自行判断
- 按已有学习历史出题，优先薄弱点和久未练习的内容
- 针对错题出复盘变式题
- 汇总已学范围、正确率、薄弱点和下一轮建议

## 学习数据

学习档案只保存在本机：

```
/Users/songyanfei/.exam-assistant/
├── state.json          # 科目、知识点、掌握度与统计
├── wrong-items.json    # 错题
├── sessions/           # 每次练习记录
└── reports/            # 可选的报告文件
```

不要写到助手云端电脑或其他 bot 的私有目录。多个 agent 共用这一份本地档案。

## 使用

把本仓库作为 skill 安装，或在对话里用 `/`、`@` 调用「考试助手」，然后：

- 丢一份材料并说开始练习
- 不给新材料时，按历史或错题复盘出题
- 需要总结时直接要报告

默认每轮 5 题，可指定题量和方式。先出题，收齐答案后再批改并回写档案。
