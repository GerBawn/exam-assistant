# 考试助手

按学习材料出题，记录对错与掌握度，并支持新知练习、错题复习、定期复习和综合练习，以及学习总结报告。四种练习方式会生成带倒计时的交互练习页；总结报告和纯讲解仍用文字。本机首页可以查看学习地图。

这是通用材料学习助手。

## 功能

- 根据你提供的文档、附件或粘贴内容出题，题型由材料自行判断
- 支持单选、判断、多选、排序、填空，以及简答、案例、计算题
- 四种练习方式：
  - 新知练习：刚学或刚录入、还没练过的知识点
  - 错题复习：从待复习错题出变式（也可按要求重做原题）
  - 定期复习：按上次练习时间复习到期的知识点（学习中 / 薄弱隔 1 天，已掌握隔 7 天）
  - 综合练习：按档案自动组卷，优先到期和新知，再补薄弱和错题
- 也可指定某份材料、某个科目或某个知识点直接练习
- 本机首页的「学习地图」按科目和知识点展示未练 / 薄弱 / 学习中 / 掌握、正确率、待复习错题和到期情况
- 汇总已学范围、正确率、薄弱点和下一轮建议

## 学习数据

数据目录是用户主目录下的 `.exam-assistant/`。下文所说的数据目录都指这里。

```
数据目录/
├── state.json          # 科目、知识点、掌握度与统计
├── wrong-items.json    # 错题
├── sessions/           # 每次练习记录
├── pages/              # 交互练习页
├── assignments/        # 已布置的试卷
└── reports/            # 可选的报告文件
```

多个 agent 共用这一份本地档案。

## 本机记录服务

练习页需要一个只监听本机的小服务，才能把作答写进 `sessions/`。

- 脚本：`tools/exam-server.js`（Node 标准库，无额外依赖）
- 地址：`http://127.0.0.1:17922/`
- 绑定 `127.0.0.1:17922`
- macOS 备用启动脚本：`tools/start-exam-server.command`

由助手在出题前启动。若该端口已经是本服务，会直接复用。启动失败时，交卷会改为下载 JSON，把文件放到 `sessions/` 即可。

首页有「最近一次试卷」「历史试卷」和「学习地图」。学习地图在 `http://127.0.0.1:17922/#map`。练习页地址形如 `http://127.0.0.1:17922/pages/文件名.html`。交卷并更新档案后，刷新学习地图即可看到最新掌握情况。

测试服务时把数据目录指向临时目录：

```bash
node tests/exam-server.test.js
```

## 倒计时与交卷

- 每套试卷都有倒计时。默认时长为「题数 × 2 分钟」，也可在出题时指定
- 时间到会自动交卷
- 作答过程中自动保存草稿；交卷后覆盖同一场记录，并保留开始作答的时间
- 回看已交卷的试卷时，沿用当时用时
- 交卷后客观题会自动判分，主观题展示评分要点，由助手批改
- 交卷记录先落在本机。做完后告诉助手，助手再读取 `sessions/` 里的记录并更新档案

## 使用

把本仓库作为 skill 安装，或在对话里用 `/`、`@` 调用「考试助手」，然后：

- 丢一份材料并说开始练习（默认按新知练习出题）
- 选择错题复习、定期复习或综合练习
- 查看掌握情况或学习地图
- 需要总结时直接要报告

题量按本轮覆盖范围和目标来定，也可指定题量、时限和方式。出题后打开本机首页作答，做完后回到对话里告诉助手。
