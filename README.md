# 考试助手

按学习材料或点名的主题生成交互练习，记录对错与掌握情况。可以练新知、复习错题、复习到期内容，也可以做综合练习。本机首页提供学习地图，学习总结和概念讲解以文字提供。

这是通用材料学习助手。仓库地址：https://github.com/GerBawn/exam-assistant

## 功能

- 根据你提供的文档、附件、粘贴内容，或点名的主题出题；没有现成材料时会查找来源并记入档案。题型由材料自行判断
- 支持单选、判断、多选、排序、填空，以及简答、案例、计算题
- 四种练习方式：
  - 新知练习：刚学或刚录入、还没练过的知识点
  - 错题复习：围绕上次作答中出错的那一步出变式，也可要求重做原题。答对变式后，对应的原错题完成复习
  - 定期复习：按上次练习时间复习到期的知识点（学习中 / 薄弱隔 1 天，已掌握隔 7 天；未练或还没有上次练习时间的立即到期）
  - 综合练习：按档案自动组卷，优先到期和新知，再补薄弱和错题
- 也可指定档案里已有的科目、知识类、知识点，或一份已经用过的材料范围直接练习
- 本机首页的「学习地图」按科目和知识点展示未练 / 薄弱 / 学习中 / 掌握、正确率、待复习错题和到期情况；有知识类时也会汇总各类的到期和薄弱情况
- 第一次练某个知识点，三题全对先记为学习中。到期后独立答对换问法的题，并达到正确率和连对要求，才升为已掌握
- 汇总已学范围、正确率、薄弱点和下一轮建议

## 学习数据

数据目录是用户主目录下的 `.exam-assistant/`。下文所说的数据目录都指这里。

```
数据目录/
├── state.json          # 科目、材料索引、知识类、知识点、掌握度与统计
├── wrong-items.json    # 错题
├── sessions/           # 每次练习记录
├── pages/              # 旧版独立 HTML 试卷
├── assignments/        # 试卷 JSON（题目、材料、参考答案与解析）
├── reports/            # 可选的报告文件
├── exam-server.js      # 本机记录服务（每次启动从仓库或 skill 覆盖复制）
├── home.html           # 本机首页壳
├── practice.html       # 共享练习页模板
└── app-chrome.inc.html # 各页共用顶栏导航
```

多个 agent 共用这一份本地档案。

## 本机记录服务

练习页需要一个只监听本机的小服务，才能把作答写进 `sessions/`。

- 脚本：`tools/exam-server.js`（Node 标准库，无额外依赖）
- 地址：`http://127.0.0.1:17922/`
- 绑定 `127.0.0.1:17922`
- macOS 备用启动脚本：`tools/start-exam-server.command`

由助手在出题前启动。启动脚本把 `exam-server.js`、`home.html`、`practice.html` 和 `app-chrome.inc.html` 复制到数据目录。若端口上的服务、数据目录和版本都一致，会直接复用该进程。已经打开的练习页遇到服务断线时，交卷会下载作答 JSON。

入口是本机首页。顶栏始终是「最近一次试卷」「历史试卷」和「学习地图」；新卷地址形如 `/practice/场次ID`，旧版 `/pages/文件名.html` 仍可打开，两者进入后也是同一套导航。更新模板后重新打开即可用新界面。交卷并更新档案后，刷新学习地图即可看到最新掌握情况。

试卷内容可通过 `GET /api/assignments/{sessionId}` 读取。回顾错题时，用场次 ID 和题目 ID 把作答与试卷对应起来。定期复习和学习地图用知识点 ID 关联跨场练习与掌握度。

测试服务时把数据目录指向临时目录：

```bash
node tests/exam-server.test.js
```

## 计时与交卷

- 普通练习显示已用时间，做完后点「交卷」
- 要求模考、练速度或指定时限时，试卷显示剩余时间，到时自动交卷。可直接说「给我出一套 15 分钟的限时卷」
- 作答过程中自动保存草稿；交卷后覆盖同一场记录，并保留开始作答的时间
- 回看已交卷的试卷时，沿用当时用时
- 交卷后客观题按标准答案字面自动判分并写入该场 session；助手复核后写回同一份成绩，历史列表与回看都读这份。主观题展示评分要点，由助手批改后写回
- 交卷记录先落在本机。做完后告诉助手，助手再读取 `sessions/` 里的记录并更新档案

## 使用

把本仓库作为 skill 安装，或在对话里用 `/`、`@` 调用「考试助手」，然后：

- 丢一份材料，或点名一个主题开始练习（档案里还不够时按新知练习出题，已有足够内容时按该范围出题）
- 选择错题复习、定期复习或综合练习；待复习内容很多时，会先整理并建议范围，有知识类时先按类建议
- 查看掌握情况或学习地图
- 需要总结时直接要报告

题量按本轮覆盖范围和目标来定，也可指定题量、时限和方式。出题后打开本机首页作答，做完后回到对话里告诉助手。
